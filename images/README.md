# 사진 폴더 안내

이 폴더에 마지막 화면(문구 위/아래 각 2줄, 한 줄당 5장)에 들어갈 사진을 넣어주세요.

## 파일 이름 규칙
아래처럼 이름을 지어서 넣어주시면 자동으로 하트에 배치돼요:

- photo1.jpg
- photo2.jpg
- photo3.jpg
- ...
- photo20.jpg

## 참고
- jpg 형식을 권장해요 (사진을 저장할 때 .jpg로 저장해주세요).
- 20장이 안 되어도 괜찮아요. 없는 번호는 자동으로 분홍색 타일로 대체돼서 페이지가 깨지지 않아요.
- 20장보다 더 넣고 싶으면, `index.html` 안의 `PHOTO_COUNT` 값을 사진 개수에 맞게 바꿔주세요.
- 사진 개수가 20장보다 적으면, 있는 사진들이 반복되어 4줄을 채워요.
- 배치: 문구 위 1번째 줄 = photo1~5, 위 2번째 줄 = photo6~10, 아래 1번째 줄 = photo11~15, 아래 2번째 줄 = photo16~20
- 각 줄은 오른쪽에서 왼쪽으로 천천히, 끊김 없이 계속 움직여요.
